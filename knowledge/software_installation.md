# Software installation

Source ID: SW-001
Audience: All employees
Environment: Fictional training company

Ask the support agent to install an app, for example "Please install Zoom". Approved catalogue
apps (Chrome, Firefox, Teams, Zoom, Slack, Visual Studio Code, Python 3, 7-Zip, Notepad++,
Acrobat Reader) are installed immediately. Licensed apps such as Photoshop, Tableau, MATLAB,
Docker Desktop, Visio and AutoCAD need approval, so the agent raises a ticket for you.
Never bypass licensing, device security or administrator permissions.
